# 🌦️ Weather App

A simple and elegant Weather App built using **HTML**, **CSS**, and **JavaScript**. This project allows users to search for any city and get real-time weather information using a public weather API.

## 🔍 Features

- ☀️ Displays current weather conditions
- 🌡️ Shows temperature, humidity, wind speed, and weather status
- 🏙️ City-based search functionality
- 📱 Responsive design suitable for mobile and desktop
- 🎨 Clean UI with weather icons

## ⚙️ Technologies Used

- HTML5
- CSS3
- JavaScript (Fetch API)
- [OpenWeatherMap API](https://openweathermap.org/api)
